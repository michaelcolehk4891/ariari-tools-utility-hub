## What Is Ariari Tools?

Ariari Tools is an HTML-based set of browser utilities collected behind one central interface. The project can be opened through its hosted browser version or downloaded and run locally, giving users more than one way to reach the included tools.

It is designed for people who want practical, lightweight utilities in a browser rather than a separate native program. Depending on the environment, the files can be opened directly or delivered through a local static server, while the hosted version provides immediate browser access.
